
# BMI Calculator

## Project Description
This is a beginner Python project that calculates Body Mass Index (BMI) using a person's weight in kilograms and height in meters.

## Features
- Accepts weight and height from the user.
- Calculates BMI.
- Classifies BMI as underweight, normal weight, overweight, or obese.
- Checks that weight and height are greater than zero.

## Technologies Used
- Python
- Git
- GitHub

## How to Run
1. Install Python.
2. Open Command Prompt in the project folder.
3. Run: `py sample_data.py`
4. Enter your weight in kilograms and height in meters.
